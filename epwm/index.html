Сдвиг таймеров ePWM

Введите снимок TBCTR, TBSTS.CTRDIR и TBPRD восьми модулей, сделанный в один и тот же момент, — страница покажет, как их счётчики идут друг относительно друга. Время считается в тактах TBCLK; момент снимка — t = 0.

Вставить из отладчика

До восьми чисел через пробел, запятую, точку с запятой или с новой строки; можно в шестнадцатеричном виде (0x3E8). Пустая строка не меняет поле. Одно число записывается во все восемь таймеров.
Колесо мыши — масштаб по времени, перетаскивание — сдвиг. Наведите курсор, чтобы увидеть значения всех счётчиков в этот такт.
Как считается

Вверх: TBCTR идёт 0 → TBPRD и сбрасывается в 0, период TBPRD + 1 тактов. Вниз: TBPRD → 0 и перезагружается TBPRD, период TBPRD + 1. Вверх-вниз: 0 → TBPRD → 0, период 2·TBPRD; здесь направление из TBSTS.CTRDIR (1 — вверх, 0 — вниз) различает два момента с одинаковым TBCTR.

Из TBCTR и направления находится место таймера внутри его периода, отсчитанное от начала периода: 0 для счёта вверх и вверх-вниз, TBPRD для счёта вниз. Сдвиг — разность этих мест у таймера и опорного, приведённая к ±½ периода: плюс значит, что таймер опережает опорный. Сдвиг считается только у таймеров с тем же периодом, что у опорного.

Предполагается, что все таймеры тактируются одним TBCLK (одинаковые CLKDIV и HSPCLKDIV) и что значения прочитаны в один такт — например, при остановке по точке останова с замороженными таймерами.
